# Santhosh Srinivasan — Data Engineer Portfolio

A responsive, static portfolio built with **HTML and CSS only**. No JavaScript or build tools required.

## Preview locally
1. Keep `index.html`, `style.css`, and `resume.pdf` in the same project folder.
2. Open `index.html` in your browser.

## Deploy with GitHub Pages
1. Create a GitHub repository named `yourusername.github.io`.
2. Upload `index.html`, `style.css`, `resume.pdf` and the `assets` folder.
3. In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. Visit `https://yourusername.github.io`.

## Before publishing
- Add your actual LinkedIn and GitHub profile URLs.
- Add repository links to each project when ready.
- Optionally add a profile photo under `assets/` and update the HTML.
- Check the contact details and resume PDF are current.

Fonts are loaded from Google Fonts; the page falls back to system fonts if unavailable.
